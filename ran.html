Welcome to My Portfolio

Introduction

Welcome to my personal portfolio, created for my Human-Computer Interaction and Web Design 1 midterm examination. This website demonstrates my knowledge of HTML5 document structure, semantic elements, accessible content, multimedia integration, and interactive forms.

As an Information Technology student, I am developing the technical knowledge and creative skills needed to build websites that communicate information clearly and are easy for users to understand and navigate.

Purpose of This Website

The purpose of this portfolio is to demonstrate how HTML elements can organize information into meaningful sections. It also provides examples of a data table, an audio player, a contact form, and navigation links.

About Me

My name is Bob Aaron Ombajin, and I am an Information Technology student interested in website development, computer technology, and digital design. I am continuously improving my understanding of how websites are structured and how users interact with digital content.

This project gives me an opportunity to practice writing organized HTML documents and applying accessibility principles to everyday website components.

My Core Development Goals

  • Semantic HTML Structuring: Using meaningful elements such as header, nav, main, section, and footer to organize content.
  • CSS Layout and Design: Understanding how shared stylesheets, spacing, colors, and layout properties create a consistent user experience.
  • Accessibility and Usability: Providing descriptive image alternatives, properly associated form labels, understandable navigation, and semantic table headings.

My Strengths and Learning Priorities

My learning priorities include attention to detail, logical problem-solving, organized coding practices, and testing website features before submission.

My Future Goal

I aim to strengthen my front-end development skills and eventually create useful, accessible, and professional websites for different users.
